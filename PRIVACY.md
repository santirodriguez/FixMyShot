# Privacy — unreleased development preview

FixMyShot processes images locally. It requests no Internet, broad photo-library, camera or location permission. There are no accounts, advertising, analytics or subscriptions. Application backup is disabled. The Android picker or an external provider may fetch cloud files independently; FixMyShot does not upload your images. Optional links open an external browser only after you choose them.

The system Photo Picker and Android share intents provide only selected images. Supported static SDR JPEG/PNG/WebP inputs are copied to private cache for review; originals are read only. Protective limits are 100 images per batch, 100 MiB per input and 1 GiB staged sources, with lower device memory limits possible. Private staged copies may contain original identifying metadata. SHA-256 fingerprints detect changed sources. Preview and thumbnail work stays local; the thumbnail cache is bounded to 24 MiB.

Export creates new PNG or lossless WebP copies. Identifying source metadata is removed from new copies by default; compatible unchanged PNG/WebP images can have metadata stripped without recompressing their image payload. PNG and metadata removal are new-session defaults. This does not redact names or other personal content visible in image pixels. Review lets you explicitly retain supported capture/digitization dates, time offsets, camera/lens make/model, artist/copyright and GPS coordinates/altitude in PNG/lossless WebP. This can disclose identity or location. Preservation is partial: printable ASCII values up to512 characters accepted by the pinned writer; orientation/dimensions are regenerated, and MakerNote, serials, thumbnails, comments, arbitrary XMP/IPTC and original paths are excluded. See docs/FORMATS.md for the exact tag set. Development acceptance boundaries are recorded in docs/TESTING.md. Recognized SDR Display P3/Adobe RGB conversion to sRGB is implemented with a visible notice, pending Android acceptance; it keeps originals intact and never transfers original ICC free text into output. Broader color/HDR handling and native HEIC/AVIF output remain incomplete development features, not accepted capabilities.

On Android 10/API 29 or later, successful copies are published to Pictures/FixMyShot through owned MediaStore entries. Older Android uses a folder explicitly selected with the system picker, where unfinished documents can be visible during writing. Saved copies remain under your control. Explicit sharing or opening gives another app a temporary read grant; that app controls what it does with the received image. FixMyShot does not post to an account automatically.

Private export journals record frozen settings, staged references and fingerprints, owned output URIs, digests and transaction state. They permit explicit restoration/retry and avoid silently duplicating uncertain outputs after a crash. Opening or rechecking an output is read only. Accepting a verified uncertain output requires your separate confirmation; hidden, changed, missing or inaccessible output cannot be accepted through that action.

On Android10/API29 or later, after checking a pending output, a separate confirmed action can remove an unfinished copy created by FixMyShot in Pictures/FixMyShot. It verifies ownership, name, format, destination and still-pending publication state before a filtered removal. Published copies and selected originals are excluded. A successful removal can make an explicit retry available; it never starts one automatically. Other providers and ambiguous states retain their recovery records.

Finishing result review removes its frozen settings/source-reference journal and releases private sources no longer needed by the current draft or another pending job. Removing images or discarding a session releases its unused staged copies; it never deletes originals or saved output copies. After a fully successful session is finished, its matching private output receipts and review acknowledgement are eligible for removal too. Interrupted private receipt cleanup is retried at a later app opening. Partial, uncertain, corrupt, mismatched or otherwise unsafe jobs retain their receipts; complete retirement of those states remains pending. Cleanup can be delayed to protect recoverable work.

At the next app opening, abandoned staged files and temporary candidates older than 24 hours are eligible for cleanup. Current draft and unreviewed-job sources are protected. Android may evict cached copies earlier, which can make a draft unavailable. Cleanup is not a background promise of deletion exactly after 24 hours and is not secure erasure on flash storage. Clearing app data or uninstalling removes ordinary private state according to Android behavior; saved output copies remain.

The synthetic development test harness runs only when explicitly launched. It creates and removes its own private/provider fixtures; CI retains synthetic reports as development evidence. Settings includes an optional HEIC/AVIF check using only synthetic images, with no gallery/provider writes or selected-image access. Its transient report includes Android version, manufacturer/model, app version/code, the installed base APK hash and synthetic outcomes/metrics. It excludes photo references, installation paths, device serials and exception text. Only a separate Share report tap opens Android’s chooser; the chosen app controls what it does with that text. FixMyShot does not upload it itself. Private diagnostic candidates are deleted after attempts, with the existing conservative24-hour cache cleanup for abandoned files; the latest report stays only in memory. Do not include private image content, full source URIs or metadata in public bug reports. The planned privacy website has not been verified as deployed.


The current editable draft checkpoints private source references and settings locally after edits, including selection and one undo snapshot. No raw EXIF or image bytes are stored in the JSON journal itself. Reopening a non-expired session restores its explicit format and metadata choices, with a visible reminder before export. More than24 hours without a saved update makes a closed session expired on the next start; current in-process drafts and unresolved export recovery retain their source protections. Cache eviction can prevent restoration. Missing or corrupt saved state requires explicit discard before a replacement session is saved; original/provider images are never deleted by that action. Checkpoint failures are visible and can be retried. Edits not yet checkpointed and pending imports may be lost on abrupt process death.


Leaving the app requests a pause before the next export image, allowing the current bounded transaction to finish while the process lives. Continuing remaining images is explicit. After all images in a matching session are saved, Finish session removes that session’s private working copies and current/undo/recovery settings, retires its consistent fully published private receipts and starts with PNG/removal defaults. Public output remains in its selected destination. Other unresolved jobs retain their source protection; cleanup failures are visible.


The latest import notice keeps only received-order positions, counts and generic failure categories in memory. It contains no source names, URIs, image bytes or metadata, survives Activity recreation with the current ViewModel, and is replaced by the next completed import or dismissed/discarded/finished session. It is not saved as diagnostic history. Dismissing it removes feedback only; it does not delete sources or published copies. Export messages use a closed localized vocabulary rather than raw journal codes or exception text.

Import progress is memory-only. Stopping finishes the current provider operation, keeps completed private additions and skips untouched offers, including those already queued when Stop is tapped. Their count is separate from failed images. A blocked provider read cannot be forcibly interrupted by this action. A later explicit picker/share offer is a new import; stopped offers do not restart automatically. No original or exported image is deleted by stopping.
