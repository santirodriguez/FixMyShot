An archive being generated in private GitHub Actions is not proof of sufficient **public, durable, usable** source access beside an eventual release. Before proposing publication, verify the actual selected APK/source asset pairing, source archive completeness/preferred editing form as applicable, notices and license terms, exact hashes, recoverability/rebuild instructions, access/retention and how source will be offered alongside the binary. The [Apache-2.0 / GPLv3 compatibility explanation](https://www.apache.org/licenses/GPL-compatibility.html) supports the previous bounded compatibility finding; it is not a blanket clearance of unknown resource provenance or all third-party obligations.
