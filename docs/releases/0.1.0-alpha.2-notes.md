<h1 align="center">FixMyShot 0.1.0-alpha.2</h1>
<p align="center"><strong>Screenshots, ready anywhere.</strong><br />A calmer editor, with room for the useful controls.</p>

> **Development prerelease for testing.** Full functional 0.1.0 acceptance is incomplete. The coverage limits below remain open.

## A clearer place to work

- One main Home logo, with a distinct information action and labelled result buttons.
- Background and Customize get their own row; detailed background choices open in a dialog.
- Common destinations appear before Google Play. Original remains the neutral new-session default.
- Status icons and the gesture indicator stay readable across dark/light Settings and return to the editor.

PNG remains the default. Lossless WebP is an explicit option. New copies remove
identifying metadata by default; originals remain unchanged. Visible image content
is still visible. Images are processed on the device.

## Before you install

Android 8 / API 26 or later; Android 8–9 storage is best effort. HEIC, AVIF and JPEG XL
output are deferred. Public documentation uses Caja Personal; this frozen APK
retains its original About attribution and personal-site links. Updating those
requires a new versioned candidate, not replacement code 2 bytes.

The same production identity and certificate are retained;
the maintainer reports a successful alpha.1/code 1 → alpha.2/code 2 update and launch.

Validation still unrecorded: actual 16 KiB runtime; the full 100-item mixed
resource/process-kill/provider exercise; exhaustive human locale/accessibility
review; wider independent privacy/opt-out/color-alpha-HDR cases; detailed
settings/default retention; and actual Obtainium install/update. These are coverage
limits, not passing results or a claim that those functions are broken.
