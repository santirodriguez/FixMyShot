> **SIGNED VALIDATION CANDIDATE.** [Download the original Actions artifact](https://github.com/santirodriguez/FixMyShot/actions/runs/41719563373/artifacts/13272275462) for installation/upgrade testing. No tag or GitHub release has been published.

A calmer editor with clearer actions, easier background choices and more readable Settings.

- Remove the repeated home branding and give information and result actions clear, labelled icons.
- Keep common destinations near the top; retain Original as the new-session default.
- Give Background and Customize their own row; keep detailed background choices in a dialog.
- Restore readable status and gesture indicators when opening Settings and returning to the editor.
- Prepare versionCode2 while preserving the exact installed alpha.1/code1 signing history.

Images stay on the device. New sessions use PNG with identifying-metadata removal;
lossless WebP is available explicitly. HEIC, AVIF and JPEG XL output remain deferred.
Removing metadata does not hide visible content.
