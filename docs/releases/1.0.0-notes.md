# FixMyShot 1.0.0

**Screenshots, ready anywhere.** A Caja Personal project.

Pick one image or a batch, keep the whole picture or frame it deliberately,
and export separate PNG or lossless WebP copies. Original files stay intact.

- Large preview, optional crop, ratios, backgrounds and per-image settings.
- Saved-result viewer, sharing and a direct next-image action.
- Offline English, Español and Català; light, dark and system appearance.
- Local processing, no Internet permission, and metadata removal by default.

Requires Android 8/API26 or later; Android 8–9 storage remains best effort.
HEIC, AVIF and JXL output are deferred. Metadata removal does not redact visible
content. Wider manual coverage is recorded in the release build receipt.

This is the first public release: `1.0.0` / Android versionCode `1`.
Future public updates use higher versionCodes and preserve the same application
ID and signing identity.

Distribution uses one FixMyShot-1.0.0-universal.apk, source materials,
BUILD-INFO.json and SHA256SUMS.txt. Obtainium uses the GitHub repository source,
stable releases and the universal APK filter. No store account is required.

The unmodified corresponding sources for this exact signed APK are supplied as the `FixMyShot-1.0.0-source-materials.tar.gz` asset **on the same public release**. `BUILD-INFO.json` and `SHA256SUMS.txt` identify the executable/source pair; retain the original GPLv3, Apache-2.0, libwebp BSD-style, Protobuf BSD-3-Clause and Android NDK cpufeatures notices. The [bounded source/notice distribution review](https://github.com/santirodriguez/FixMyShot/blob/v1.0.0/docs/releases/1.0.0-7649f0e-final-source-license-disposition.md) documents the complete captured original runtime library inventory and conditions. The archived source instructions do not assert a verified **offline** Android build. No original signed APK bytes or source materials have been altered.

### Acceptance limitations

The original signed 1.0.0 APK was installed, launched and relaunched successfully in an Android 15 **16 KiB emulator**; this was not a physical-device/native export test. PNG/lossless WebP functionality also has existing automated/debug coverage and explicit bounded maintainer acceptance. The full 100-item stress exercise, exhaustive human language/accessibility review, and independent signed-output EXIF/GPS/color inspection were **not run** and are not claimed as passes. Android 8–9 storage behavior is best effort; social destination presets are layout guidance rather than certified social-app upload compatibility. Obtainium initial install can be evaluated only after publication; an actual higher-code update requires a future public version.
