# FixMyShot 1.0.0

**Screenshots, ready anywhere.** A Caja Personal project.

Pick one image or a batch, keep the whole picture or frame it deliberately,
and export separate PNG or lossless WebP copies. Original files stay intact.

- Large preview, optional crop, ratios, backgrounds and per-image settings.
- Saved-result viewer, sharing and a direct next-image action.
- Offline English, Español and Català; light, dark and system appearance.
- Local processing, no Internet permission, and metadata removal by default.

Requires Android 8/API26 or later; Android 8–9 storage remains best effort.
HEIC, AVIF and JXL output are deferred. Metadata removal does not redact visible
content. Wider manual coverage is recorded in the release build receipt.

Private alpha.2/code2 testers must uninstall that alpha before installing this
first public code1 release. App-private drafts/preferences are removed. This is
not an alpha upgrade; later public updates will increase the versionCode.

Distribution uses one FixMyShot-1.0.0-universal.apk, source materials,
BUILD-INFO.json and SHA256SUMS.txt. Obtainium uses the GitHub repository source,
stable releases and the universal APK filter. No store account is required.
