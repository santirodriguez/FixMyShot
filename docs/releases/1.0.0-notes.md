# FixMyShot 1.0.0

**Screenshots, ready anywhere.**

FixMyShot is a lightweight Android app for preparing screenshots to share. Keep the whole image, adjust its frame or crop deliberately, and export a new copy without changing the original.

## Download for Android

**[Download FixMyShot 1.0.0 — signed universal APK](https://github.com/santirodriguez/FixMyShot/releases/download/v1.0.0/FixMyShot-1.0.0-universal.apk)**

Android 8.0+ (API 26) · Free and open source · No account or Internet permission.

To follow stable releases, add [FixMyShot on GitHub](https://github.com/santirodriguez/FixMyShot) to **Obtainium** and select the universal APK. Obtainium installation and an in-place update have not yet been verified end to end.

## Highlights

- Import one image or a batch and review the result in a large preview.
- Keep all content, or deliberately choose crop, ratios, backgrounds and per-image adjustments.
- Export PNG (the new-session default) or lossless WebP, then view or share the saved copy.
- Work offline in English, Español or Català, with light, dark and system themes.
- Process images locally. Identifying metadata is removed by default; visible information in a screenshot is **not** redacted.

**Compatibility:** Android 8–9 storage is best effort. HEIC, AVIF and JXL export are not available in this release.
