## Less work between a screenshot and its destination

Choose one screenshot or a batch, keep the full capture by default, then
save and share a fresh copy. Original files remain unchanged.

| What you can do | Why it helps |
| --- | --- |
| Import or receive shared images | Start from the picker or another app |
| Keep Original or choose a destination | Frame the capture without guessing a platform |
| Use Automatic or Customize | Make a quick export or deliberately adjust framing |
| Preserve content or explicitly crop | Control the result without stretching pixels |
| Use PNG or lossless WebP | Choose a lossless output; new sessions always start with PNG |
| Export a batch with per-image exceptions | Reuse common settings without erasing individual edits |
| View/share results or edit another image | Continue after a successful export without discarding work |

## Privacy and control

Processing stays on the device, with no Internet permission, account,
telemetry or advertisements. Identifying metadata is removed by default;
an explicit session/per-image opt-out preserves only the documented
allowlist where supported. Metadata removal does not redact visible
content. Supported static SDR inputs and bounded resource checks apply.
English, Español and Català are included.

## Before a public install

- HEIC, AVIF and JPEG XL outputs are deferred from 0.1.0. Existing deferred
  draft values remain readable and explicitly unavailable; no automatic
  format replacement occurs. JPEG input does not imply JPEG output.
- Android 8 / API 26 is the declared minimum; older-device behavior is best
  effort. Current automated regression acceptance is API 36, with optional
  legacy-provider coverage not run in the latest current-profile batch.
- Current debug builds are isolated diagnostics, not the production
  signing identity or an accepted same-certificate upgrade path.
- Synthetic performance observations are not physical peak-memory/p95
  or universal device/viewer/accessibility guarantees.

## Downloads and updates

Public download and checksum links will be added only after the exact
signed assets are authorized, published and checked. The intended first
channel is GitHub, with Obtainium support verified on those actual bytes.
Do not treat an unsigned build or a debug APK as the public release.
