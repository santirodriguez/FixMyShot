# FixMyShot icon1 — isolated 16 KiB and synthetic privacy validation

**Status: PREPARED_NOT_EXECUTED.** This document describes an opt-in CI test profile. It is not a passing emulator test or proof that the signed production APK ran on 16 KiB pages.

## Activation boundary

The existing Android bootstrap workflow must remain on its standard profile unless a **later, separately approved** release-branch request changes the final line of `.ci/android-validation-request.txt` to exactly `profile=16k-privacy`. This preparation does **not** modify that request. PR review events must retain their ordinary API 36 smoke coverage, and workflow/test/documentation pushes alone must not dispatch Actions.

When explicitly activated, the job should consume the same-run source-bound debug and instrumentation APK artifacts, using Android 35, x86_64, `google_apis_ps16k`, and a version-pinned emulator runner supporting 16 KiB system images. Standard / extended profiles should retain their existing runner and API 36 / best-effort API 26–28 coverage.

## Required evidence and gates

- `adb shell getconf PAGE_SIZE` and in-app `Os.sysconf(_SC_PAGE_SIZE)` must both report **16384**. Missing emulator images, invalid architecture, 4096-byte pages, unavailable evidence or incomplete tests fail closed.
- Existing `CodecSmokeTest` should verify 80 synthetic PNG/WebP encodes with decoded-pixel/alpha assertions. Android 35 normally uses the system `ANDROID_WEBP_LOSSLESS` route, **not** libwebp JNI; the new isolated `SixteenKPrivacyTest` probes actual native libwebp JNI lossless output independently without changing the production API.
- Existing `MetadataPolicyTest` uses synthetic EXIF/GPS/XMP to check default removal and opt-in allowlist preservation. The new test also saves four synthetic app-private PNG/WebP output files; a stdlib host checker independently parses PNG CRCs, WebP RIFF structure and EXIF/GPS tags, and refuses forbidden identifying metadata.
- Collect only synthetic input/output and bounded metadata. Record Android API, ABI, actual page size, instrumentation log, 80 encode results, direct native WebP evidence, four privacy samples and an independent host verdict. Do not inspect or upload real user images.
- Any successful result is explicitly `PASS_SYNTHETIC_DEBUG_ONLY`: this job tests a newly built **debug** APK and does not independently install/launch the already signed production 1.0.0 APK.
